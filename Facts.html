പനി(Fever)

പനി (Fever) എന്നാൽ എന്താണ്?

നമ്മുടെ ശരീരത്തിന്റെ സാധാരണ ചൂട് 37°C (98.6°F) ആണ്. ഈ ചൂട് ഇതിലും കൂടുതൽ ആകുന്ന അവസ്ഥയ്ക്കാണ് നമ്മൾ പനി എന്ന് പറയുന്നത്.

എന്തുകൊണ്ടാണ് പനി വരുന്നത്?

നമ്മുടെ ശരീരത്തിനുള്ളിൽ അണുക്കൾ (വൈറസ്, ബാക്ടീരിയ) കയറി വരുമ്പോൾ, നമ്മുടെ ശരീരത്തിലെ വെളുത്ത രക്താണുക്കൾ തലച്ചോറിന് ഒരു സന്ദേശം അയക്കും. "ചൂട് കൂട്ടൂ, ശത്രുക്കൾ വന്നിട്ടുണ്ട്!" എന്ന്. അപ്പോൾ തലച്ചോർ ശരീരത്തിന്റെ ചൂട് കൂട്ടുന്നു.

പനി നല്ലതാണോ?

അതെ! പനി നമ്മുടെ ശത്രുവല്ല, നമ്മുടെ കാവൽക്കാരനാണ്. ഈ കൂടിയ ചൂടിൽ പല അണുക്കൾക്കും ജീവിക്കാൻ പറ്റില്ല. പനി വരുന്നു എന്ന് പറഞ്ഞാൽ, നമ്മുടെ ശരീരം രോഗത്തിനെതിരെ യുദ്ധം ചെയ്യുന്നു എന്നാണ് അർത്ഥം. രോഗം മാറുമ്പോൾ പനിയും തനിയെ മാറും.

നമ്മുടെ പ്രതിരോധ സംവിധാനം ലളിതമായി

🏰 നമ്മുടെ ശരീരം ഒരു കൊട്ടാരം പോലെ!

നമ്മുടെ ശരീരത്തെ ഒരു വലിയ കൊട്ടാരമായി സങ്കൽപ്പിക്കൂ. ഈ കൊട്ടാരത്തെ രോഗാണുക്കളിൽനിന്ന് സംരക്ഷിക്കാൻ ഒരു വലിയ സുരക്ഷാ സംവിധാനമുണ്ട്. അതാണ് Immune System (പ്രതിരോധ സംവിധാനം)!


🏰 1. കൊട്ടാരത്തിന്റെ പുറംമതിൽ — Skin (ചർമ്മം)

ഒരു കൊട്ടാരത്തിന്റെ പുറംമതിൽ ശത്രുക്കളെ അകത്തേക്ക് കടക്കുന്നതിൽനിന്ന് തടയുന്നതുപോലെ നമ്മുടെ ചർമ്മം പല രോഗാണുക്കളെയും ശരീരത്തിനകത്ത് പ്രവേശിക്കുന്നതിൽനിന്ന് തടയുന്നു.


🚪 2. പ്രവേശന കവാടങ്ങൾ — മൂക്കും വായും

കൊട്ടാരത്തിന്റെ കവാടങ്ങളിൽ കാവൽക്കാരുള്ളതുപോലെ നമ്മുടെ മൂക്കിലെ രോമങ്ങളും കഫവും ശ്വാസനാളത്തിലെ ചെറിയ രോമങ്ങൾ പോലുള്ള ഘടനകളും രോഗാണുക്കളെ തടയാനും പുറത്തുകളയാനും സഹായിക്കുന്നു. ഉമിനീരും കണ്ണുനീരും (കണ്ണ് നീരിലെ ലൈസോസൈം)പോലുള്ള ദ്രാവകങ്ങൾക്കും രോഗാണുക്കൾക്കെതിരെ സംരക്ഷണ പ്രവർത്തനങ്ങളുണ്ട്.


🚨 3. ആദ്യത്തെ കാവൽക്കാർ — Innate Immune System

ചില ശത്രുക്കൾ കൊട്ടാരത്തിനകത്ത് കടന്നാൽ ഉടൻ പ്രവർത്തിക്കുന്ന സൈന്യത്തെപ്പോലെ നമ്മുടെ ശരീരത്തിൽ ഒരു പ്രതിരോധ സംവിധാനമുണ്ട്. ഇതിനെ Innate Immunity (ജന്മസഹജ പ്രതിരോധശേഷി) എന്നു വിളിക്കുന്നു.


ഇതിലെ ചില വെളുത്ത രക്താണുക്കൾ രോഗാണുക്കളെ തിരിച്ചറിഞ്ഞ് അവയെ വിഴുങ്ങി നശിപ്പിക്കുന്നു. ആവശ്യമെങ്കിൽ ശരീരത്തിൽ വീക്കം പോലുള്ള പ്രതിരോധ പ്രതികരണങ്ങളും ഉണ്ടാകാം.


📢 4. അടിയന്തര സന്ദേശ സംവിധാനം — Chemical Signals

കൊട്ടാരത്തിൽ ശത്രുക്കൾ എത്തിയാൽ മറ്റു സൈനികരെ അറിയിക്കുന്നതുപോലെ ശരീരത്തിലെ ചില കോശങ്ങൾ രാസസന്ദേശങ്ങൾ പുറത്തുവിടുന്നു. ഇതിലൂടെ കൂടുതൽ പ്രതിരോധ കോശങ്ങൾക്ക് പ്രശ്നമുള്ള സ്ഥലത്തേക്ക് എത്താൻ കഴിയും.


⚔️ 5. പ്രത്യേക പരിശീലനം നേടിയ സൈന്യം — Adaptive Immune System

ശത്രുക്കളെ തിരിച്ചറിഞ്ഞ് അവർക്കെതിരെ പ്രത്യേകമായി പ്രവർത്തിക്കുന്ന സൈന്യത്തെപ്പോലെയാണ് Adaptive Immune System (സ്വായത്ത പ്രതിരോധ സംവിധാനം).


ഇതിൽ പ്രധാനപ്പെട്ട രണ്ട് വിഭാഗങ്ങളുണ്ട്:


  • B Cells: ഇവയിൽ ചിലത് ആന്റിബോഡികൾ (Antibodies) നിർമ്മിക്കുന്ന പ്ലാസ്മ കോശങ്ങളായി മാറുന്നു. ആന്റിബോഡികൾ പ്രത്യേക രോഗാണുക്കളെയോ അവയുടെ ഭാഗങ്ങളെയോ തിരിച്ചറിഞ്ഞ് അവയെ നിർവീര്യമാക്കാനോ മറ്റു പ്രതിരോധ പ്രവർത്തനങ്ങൾക്ക് സഹായിക്കാനോ കഴിയും.

  • T Cells: ചില T കോശങ്ങൾ മറ്റു പ്രതിരോധ കോശങ്ങളെ പ്രവർത്തിപ്പിക്കാൻ സഹായിക്കുന്നു. മറ്റുചില T കോശങ്ങൾക്ക് വൈറസ് ബാധിച്ച ശരീരകോശങ്ങളെ തിരിച്ചറിഞ്ഞ് നശിപ്പിക്കാൻ കഴിയും.

🧠 6. പഴയ ശത്രുക്കളെ ഓർത്തുവയ്ക്കുന്ന സൈന്യം — Memory Cells

ഒരു ശത്രുവിനെ നേരിട്ടശേഷം അതിനെക്കുറിച്ച് വിവരങ്ങൾ ഓർത്തുവയ്ക്കുന്ന സൈന്യത്തെ സങ്കൽപ്പിക്കൂ.


അതുപോലെ ചില B Cells, T Cells എന്നിവ Memory Cells (ഓർമ്മകോശങ്ങൾ) ആയി മാറുന്നു. അതേ രോഗാണുവിനെ വീണ്ടും നേരിടുമ്പോൾ ശരീരത്തിന് കൂടുതൽ വേഗത്തിൽ ശക്തമായ പ്രതിരോധ പ്രതികരണം ഉണ്ടാക്കാൻ ഇവ സഹായിക്കുന്നു.


🌡️ 7. കൊട്ടാരത്തിലെ അലാറം — Fever (പനി)

ശരീരത്തിൽ അണുബാധയുണ്ടാകുമ്പോൾ പ്രതിരോധ സംവിധാനത്തിന്റെ സന്ദേശങ്ങൾ തലച്ചോറിലെ ശരീരതാപനില നിയന്ത്രിക്കുന്ന ഭാഗത്തെ സ്വാധീനിക്കാം. അപ്പോൾ ശരീരത്തിന്റെ താപനില ഉയർന്ന് പനി ഉണ്ടാകാം.


പനി പല അണുബാധകളോടുമുള്ള ശരീരത്തിന്റെ പ്രതികരണമാണ്. എന്നാൽ എല്ലാ പനിയും ഒരേ രോഗം മൂലമല്ല ഉണ്ടാകുന്നത്.

💉 8. ഇനി വാക്സിന്റെ രഹസ്യം!

ഇവിടെയാണ് വാക്സിന്റെ പ്രധാനപ്പെട്ട പങ്ക്!


ഒരു പുതിയ ശത്രുവിനെ നേരിടുന്നതിനു മുമ്പ് കൊട്ടാരത്തിലെ സൈന്യത്തിന് അതിനെ തിരിച്ചറിയാനുള്ള പരിശീലനം നൽകുന്നതുപോലെയാണ് വാക്സിൻ പ്രവർത്തിക്കുന്നത്.


വാക്സിൻ പ്രതിരോധ സംവിധാനത്തിന് ഒരു പ്രത്യേക രോഗാണുവിനെ തിരിച്ചറിയാൻ സഹായിക്കുന്ന ഘടകം അവതരിപ്പിക്കുന്നു. അതിലൂടെ ആ രോഗാണുവിനെതിരെ പ്രതിരോധ പ്രതികരണം രൂപപ്പെടാനും മെമ്മറി കോശങ്ങൾ ഉണ്ടാകാനും കഴിയും.


ശ്രദ്ധിക്കുക: എല്ലാ വാക്സിനുകളിലും നിർജീവമായ വൈറസുകളോ ബാക്ടീരിയകളോ അല്ല ഉള്ളത്. ചിലതിൽ നിർജീവമാക്കിയതോ ദുർബലപ്പെടുത്തിയതോ ആയ രോഗാണുക്കൾ ഉണ്ടാകാം; മറ്റുചിലതിൽ രോഗാണുവിന്റെ ഭാഗങ്ങളോ അതിനെ തിരിച്ചറിയാൻ സഹായിക്കുന്ന മറ്റ് ഘടകങ്ങളോ ഉണ്ടായിരിക്കും.


💡 ചുരുക്കത്തിൽ

നമ്മുടെ ശരീരത്തിലെ പ്രതിരോധ സംവിധാനം ഒരു കൊട്ടാരത്തിന്റെ സുരക്ഷാ സംവിധാനത്തെപ്പോലെയാണ്:


  • 🏰 ചർമ്മം — പുറംമതിൽ
  • 🚪 മൂക്കും വായും — പ്രവേശന കവാടങ്ങളിലെ പ്രതിരോധം
  • 🚨 ജന്മസഹജ പ്രതിരോധ സംവിധാനം — ആദ്യത്തെ കാവൽക്കാർ
  • ⚔️ B Cells, T Cells — പ്രത്യേക പ്രതിരോധ സൈന്യം
  • 🧠 Memory Cells — പഴയ ശത്രുക്കളെ ഓർത്തുവയ്ക്കുന്ന സൈന്യം
  • 💉 വാക്സിൻ — രോഗാണുവിനെ തിരിച്ചറിയാൻ പ്രതിരോധ സംവിധാനത്തെ പരിശീലിപ്പിക്കുന്ന മാർഗം

നമ്മുടെ ശരീരം ഒരു കൊട്ടാരമാണെങ്കിൽ, Immune System അതിനെ സംരക്ഷിക്കുന്ന ബുദ്ധിമാനായ സുരക്ഷാ സംവിധാനമാണ്!
